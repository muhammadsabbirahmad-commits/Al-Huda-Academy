# 🏫 Al-Huda-Academy

**Al-Huda-Academy** is a comprehensive, multi-module Android application designed for managing school and madrasah operations efficiently. This project is structured using modern Kotlin architecture and managed entirely via GitHub.

---

## 🚀 Project Architecture & Modules

The application is divided into several feature-specific modules to maintain clean code and scalability:

* **`app`** - Main host application and dashboard hub.
* **`feature_auth`** - User authentication, Login, and Registration.
* **`feature_admin`** - Administrative panel for managing school data, teachers, and students.
* **`feature_attendance`** - Digital attendance tracking for students and staff.
* **`feature_fees`** - Fee collection and payment tracking system.
* **`feature_exam`** - Exam scheduling, results, and automated grading system.
* **`feature_notice`** - Notice board for school announcements and urgent alerts.
* **`feature_routine`** - Daily class routine and timetable management.
* **`feature_homework`** - Assignment and homework tracking for classes.
* **`feature_library`** - Library book issuing and inventory management.
* **`feature_transport`** - School bus tracking and route management.
* **`feature_hostel`** - Hostel room allocation and student accommodation.
* **`feature_staff`** - Staff records, teacher management, and payroll tracking.
* **`feature_settings`** - App configurations, theme preferences, and user profiles.

---

## 🛠️ Tech Stack
* **Language:** Kotlin (`.kt`)
* **Build System:** Gradle (`settings.gradle.kts`, `build.gradle.kts`)
* **Architecture:** Multi-Module Clean Architecture
